# Contractbook Style Template

A modern, playful contract management landing page template inspired by Contractbook's design system.

## 🎨 Design System

**Theme:** Playful professionalism, high-contrast clarity

### Color Palette

| Color | Hex | Usage |
|-------|-----|-------|
| Washed Black | `#1a1a1a` | Primary text, icons, borders |
| Pure White | `#ffffff` | Page backgrounds, cards |
| Pearl | `#f7f7f3` | Secondary backgrounds |
| Beige | `#f0f0ec` | Input fields, secondary cards |
| Royal Blue | `#1009f6` | Accent cards, headlines |
| Energy Gold | `#ffba09` | Primary CTAs, buttons |
| Sky Blue | `#add3e5` | Info cards, decorative |
| Deep Moss | `#304801` | Rich accent backgrounds |
| Thistle Bloom | `#e3c7de` | Soft accents, illustrations |

### Typography

- **Font:** Inter (Abcwhyte substitute)
- **Weights:** 400, 700
- **Scale:** 11px to 48px

### Components

- **Primary Button:** Energy Gold bg, black text, pill shape (999px radius)
- **Secondary Button:** Transparent, dark border, pill shape
- **Cards:** 24px radius, generous padding (48px)
- **Inputs:** Beige bg, 4.375px radius

## 📄 Pages/Sections

1. **Navigation** - Sticky header with logo and CTAs
2. **Hero** - Bold headline with playful decorative elements
3. **Features** - 6 feature cards in grid
4. **Accent Section** - Royal Blue background with content
5. **Pricing** - 3-tier pricing cards
6. **CTA** - Dark section with conversion focus
7. **Footer** - Multi-column links

## 🚀 Usage

1. Open `index.html` in your browser
2. Customize colors in the Tailwind config
3. Replace content with your own
4. Deploy to live site

## 🎯 Key Features

- Fully responsive
- High-contrast design
- Playful rounded shapes
- Bold accent colors
- Clean typography
- No external dependencies
