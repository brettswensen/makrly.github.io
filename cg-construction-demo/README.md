# CG Construction - Handyman Services Website

A professional, trustworthy website for CG Construction, a handyman business serving Saratoga Springs.

## 🎨 Design

**Theme:** Professional, Trustworthy, Clean Construction Blue-Gray

### Color Palette

| Color | Hex | Usage |
|-------|-----|-------|
| Primary | `#1e5aa8` | Main CTAs, trust elements |
| Primary Dark | `#154785` | Hover states |
| Accent | `#f59e0b` | CTAs, highlights (construction orange) |
| Success | `#059669` | Ratings, checkmarks |
| Slate 50 | `#f8fafc` | Light backgrounds |
| Slate 100 | `#f1f5f9` | Section backgrounds |
| Slate 700 | `#334155` | Headings |
| Slate 600 | `#475569` | Body text |

1. Open `index.html` in your browser
2. Customize business info (phone, email, etc.)
3. Add real customer reviews

6. Deploy to live site
