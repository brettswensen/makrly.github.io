# Headspace Style Template

A complete landing page template inspired by Headspace's warm, modern, and playful design system.

## 🎨 Design System

**Theme:** Warm Modern Playfulness — like a friendly, brightly lit studio full of soft shapes and uplifting colors.

### Color Palette

| Color | Hex | Usage |
|-------|-----|-------|
| Sky Connect | `#0061ef` | Primary buttons, links, CTAs |
| Sunshine Burst | `#ffce00` | Accents, banners, highlights |
| Deep Plum | `#3b197f` | Illustrations, thematic sections |
| Ocean Glimmer | `#00a4ff` | Icons, illustrations |
| Blush Petal | `#ffa1cc` | Soft accents |
| Forest Calm | `#02873a` | Success states, growth themes |
| Inkwell Gray | `#4b4c4d` | Primary text |
| Cloud Whisper | `#f9f4f2` | Background surfaces |
| Pure White | `#ffffff` | Cards, elevated surfaces |

### Typography

- **Font:** Inter (system fallback)
- **Weights:** 400 (body), 500 (subheadings), 700 (headings)
- **Scale:** 12px to 48px with careful letter-spacing

### Components Included

- ✅ Accent Banner (Sunshine Burst promotional strip)
- ✅ Sticky Navigation with logo and CTAs
- ✅ Hero Section with decorative gradients
- ✅ Feature Cards Grid (6 cards)
- ✅ Two-column Content Section with feature pills
- ✅ Meditation Categories with Tab Navigation
- ✅ Pricing Cards (3 tiers)
- ✅ Newsletter Subscription Form
- ✅ Multi-column Footer

## 🚀 Usage

1. Open `index.html` in your browser
2. Customize colors in the Tailwind config section
3. Replace content with your own
4. Add your own images/illustrations
